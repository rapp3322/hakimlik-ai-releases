# Hâkimlik AI

Hâkimlik sınavına hazırlık için geliştirilen Windows masaüstü uygulaması.

## Özellikler
- PDF kitap okuma
- Derslere göre kaynak yönetimi
- OCR ile taranmış PDF desteği
- Yapay zekâ destekli çalışma araçları
- Otomatik güncelleme sistemi

## Güncellemeler
Bu depo, Hâkimlik AI uygulamasının imzalı Windows kurulum ve otomatik güncelleme dosyalarını barındırır.

Uygulamanın kaynak kodları bu depoda paylaşılmamaktadır.
